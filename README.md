# REST API и контрактные тесты

Набор pytest-тестов для публичного JSONPlaceholder API. OpenAPI-контракт находится в `openapi.yaml`; схемы запросов и ответов проверяются через `jsonschema`.

## Запуск

Требуется Python 3.10 или новее.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pytest -v
```

Нужен доступ к интернету: проверки выполняются против `https://jsonplaceholder.typicode.com`.

## Покрытие

- Получение списка и отдельного поста, включая проверку ответа по OpenAPI-схеме.
- Создание поста и проверка ответа по контракту.
- Проверка существующего граничного ID и отрицательные сценарии для несуществующих и некорректных ID.
- Проверка обязательного поля в OpenAPI-схеме запроса.

JSONPlaceholder — демонстрационный API: `POST /posts` возвращает имитацию созданного ресурса, но не сохраняет его и не выполняет серверную валидацию входных полей. Поэтому проверка пустых строк документирует поведение mock-сервиса, а не ожидает отказа валидации.
